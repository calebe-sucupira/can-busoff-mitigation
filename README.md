# CAN Bus-Off Mitigation

Firmware, hardware and experimental tools developed for research on mitigation of Bus-Off risk in CAN networks.

## Structure

- `firmware/pico-injector`: RP2040-based transient injection controller
- `firmware/node-a`: CAN transmitting node
- `firmware/node-b`: CAN receiving node
- `hardware`: schematics and PCB files
- `analysis`: experimental data processing
- `docs`: auxiliary documentation
